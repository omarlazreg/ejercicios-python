```

IMAGEN         → Plantilla estática, de solo lectura, con todo lo
                 necesario para crear un contenedor.

CONTENEDOR     → Instancia en ejecución de una imagen; la imagen
                 "cobra vida" y hace algo.

DOCKERFILE     → Archivo de texto con instrucciones paso a paso
                 para construir una imagen.

DOCKER BUILD   → Comando que lee el Dockerfile y genera la imagen.

DOCKER RUN     → Comando que arranca un contenedor a partir de
                 una imagen.

REGISTRY       → Servidor/repositorio donde se almacenan y
                 comparten imágenes (Docker Hub, ECR, ACR...).

DOCKER PUSH    → Sube una imagen local a un registry.

DOCKER PULL    → Descarga una imagen desde un registry a local.

VOLUMEN        → Espacio de almacenamiento persistente, fuera del
                 contenedor, para que los datos no se pierdan.

DOCKER COMPOSE → Herramienta para definir y levantar varios
                 contenedores conectados entre sí con un solo comando.

DOCKER ENGINE  → El motor/software que hace funcionar todo esto en
                 una máquina (es lo que "instalas").

DOCKER HUB     → El registry público más popular, propiedad de Docker.
```
